QUESTION: Q3
Every SKILL.md invokes its companion Python script through the environment variable ${CLAUDE_SKILL_DIR}, e.g. uv run "${CLAUDE_SKILL_DIR}/scripts/okf_validate.py" $ARGUMENTS, rather than any hardcoded or repo-relative path. CLAUDE_SKILL_DIR is populated by the host at invocation time to point at the currently-loaded skill's own directory, whatever that directory happens to be — inside a plugin install or inside a standalone skills.sh install. Both layouts coexist in the same repo (".claude-plugin/ makes it a plugin marketplace; skills/<name>/SKILL.md makes it skills.sh-discoverable"), and each skill folder ships its own scripts/ subdirectory alongside its SKILL.md.
The constraint: a script must always be referenced relative to its own SKILL.md's directory, never by an absolute path or a path assuming a specific repo root/plugin-cache location, since the two install mechanisms place the skill directory in different physical locations. The one wrinkle is the okf skill, which reaches into a sibling with ${CLAUDE_SKILL_DIR}/../validate/scripts/okf_validate.py, which only works if the sibling is installed alongside it at a fixed relative offset.
