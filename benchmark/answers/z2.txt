QUESTION: Q6
The trust tier isn't stored anywhere — it's computed on the fly, client-side, in the visualizer's JS, from the verified field in each concept's YAML frontmatter. The script reads generated/verified from frontmatter and embeds the raw verified list into each node's JSON. The HTML/JS payload then derives the tier at render time in trustTier(): no verified entries → "unverified"; any entry with by starting with human: → "human-reviewed"; otherwise → "machine-confirmed". This is deliberate per OKF spec §5.3 ("Trust tiers") — the code comment states "the trust tier is derived, never stored," so producers only ever write raw verification events, and every consumer computes the same tier consistently from those events rather than trusting a producer-asserted label that could be stale or spoofed.
