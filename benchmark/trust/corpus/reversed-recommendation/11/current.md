# Organising Ashgrove policy

Ownership follows the resource: the team that owns a resource type owns the
rules about it.

## Structure

The recommended structure is several small sets, one per resource type, each
owned and reviewed by its team. Sets combine by deny-overrides, so a team can
tighten its own rules without coordinating and cannot loosen another team's.

## Review

Each set is small enough to review in one sitting; a change touching two sets
needs both owners, which is the point.
